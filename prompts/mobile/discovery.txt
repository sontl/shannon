<systematic_approach>
Execute all phases below. Do not skip any phase.

## Phase 1: App Launch and Initial Survey
- Launch the app via Appium
<!-- DISABLED 2026-05-05: screenshot/image saving disabled — keep as reference
- Take a screenshot of each main screen
-->
- Inspect the UI hierarchy to enumerate all interactive elements (buttons, input fields, links, tabs)
- Navigate through all tabs, menus, and accessible screens
- Document the complete screen flow map

## Phase 2: Network Traffic Capture
- Navigate through all app screens and features while observing UI/API behavior
- Document every API endpoint the app contacts: URL, method, headers, request body, response structure (derive from OpenAPI schema + UI interactions)
- Note authentication tokens, session cookies, and API keys in headers

## Phase 3: API Endpoint Analysis
- For each discovered endpoint, document: HTTP method, path, query parameters, request body schema, response schema, authentication requirements
- Test for undocumented endpoints by fuzzing common API paths
- Check for versioned APIs (v1, v2, etc.)
- Identify file upload endpoints, WebSocket connections, and GraphQL endpoints

## Phase 4: Local Storage Inspection
- Use Appium to inspect app data directories where accessible
- Document any local databases, shared preferences, or keychain entries the app creates
- Note what sensitive data is stored locally

## Phase 5: Deep Link and Intent Discovery
- Test for registered deep link schemes (custom URL schemes, universal links)
- Document any inter-app communication patterns

</systematic_approach>
